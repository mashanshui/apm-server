## 阅读与维护

新成员按“当前实现 → 工程结构 → 处理链路 → 持久化与安全 → 构建运行 → 测试”阅读。后端内部变更同步本目录；影响平台、前端、客户端或公开契约时同步对应根目录文档。正式 API 不在这里重复定义。

历史证据保留日期、环境和局限；本次验证记录独立追加，不把迁移当作原功能重新验收。文档只移动后端专属内容，混合主题保留平台摘要并链接到唯一正文。
