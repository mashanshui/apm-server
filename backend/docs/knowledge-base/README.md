新成员按“当前实现 → 工程结构 → 处理链路 → 存储/安全 → 构建/测试”阅读；页面和浏览器细节见[前端知识库](../../../frontend/docs/knowledge-base/README.md)。

维护当前说明时原位修订，删除已失效描述，不在页首/页尾逐轮追加进度、测试计数、部署结果或内容迁移清单。日常操作输出留在任务结果/CI；有复现价值的专项基线保留日期、环境、命令、关键测量与限制，在本导航登记唯一入口。关键架构取舍由[平台决策](../../../docs/knowledge-base/10-架构决策记录.md)维护，具体规则遵循[平台维护约定](../../../docs/knowledge-base/README.md#内容归属与维护约定)。
