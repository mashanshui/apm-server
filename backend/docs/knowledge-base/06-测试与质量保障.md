## 当前执行方式与分层

在根目录使用 `./backend/gradlew.bat -p backend clean build --no-daemon` 完整编译、测试并打包；仅运行测试使用同一入口的 `test` 任务。报告位于 `backend/build/reports/tests/test/`，机器可读结果位于 `backend/build/test-results/test/`。

| 层次 | 重点与限制 |
|---|---|
| JUnit / MockMvc | 业务校验、协议、鉴权、幂等、查询和关键失败路径 |
| ArchUnit | 跨模块 API、internal 隔离、依赖白名单和无环（含 memory 模块） |
| SQL / Dashboard 资源检查 | 校验类路径资源结构，不代表数据库实际执行 |
| PostgreSQL Testcontainers | Docker 可用时执行迁移和 JPA schema 校验；跳过必须单列 |
| processor fixture | 默认使用类路径中的真实 v3 Base64 夹具；可用 `-Drhea.jank.fixture` 指定绝对路径 |
| JVM / ClickHouse 专项基线 | 见[性能基线](jank-performance-baseline.md)，不能外推生产容量 |

共享人工期望值保留在[Crash 固定数据集](../../../docs/crash-fixed-dataset.md)和[卡顿固定数据集](../../../docs/jank-fixed-dataset.md)。本次目录验证不执行写入型 ClickHouse 固定数据集脚本。
