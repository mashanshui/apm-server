## 后端能力摘要

- Java 21、Spring Boot 模块化单体；Crash/Jank/Memory 各自拥有存储端口。正常管理域需要 PostgreSQL，即使遥测选择内存模式也不能省略。
- JSON/gzip v2 接收、v3 卡顿 ZIP、内存报告 multipart、UUID v4 进程身份及幂等写入已实现；当前工作区 processor 固定为 Maven Local 的 `1.0.4`，支持主线程异步采样类型 `24`；尚未发布远程制品，云端服务未升级。
- Crash/Jank 个例总览、趋势、Issue 与摘要分页，以及内存报告筛选、聚合、分页和趋势均已下推 ClickHouse，并设置资源预算；内存适配器保留参考计算。各领域容量证据分别验收。
- Spring Session JDBC、CSRF、应用成员授权、永久 App Key、网页 mapping 管理、后台固定还原、应用查询 Token 和 19 个 Agent GET 入口已实现；MCP 为独立 TypeScript 进程。
- `agent` 域提供单事件证据、应用 Worker、任务/Run、租约、报告和停止审计。当前宿主直接读取源码，只访问新建契约任务，证据 3/报告 4 绑定 evidenceId/runId；构建源码登记已移除。默认开关关闭，控制面已有有限云端验收，执行位置仍是宿主本地，见[分析专题](local-analysis.md)。
