# Performance 项目知识库

本工程位于平台仓库 `android/`，可由 Android Studio 独立打开。平台架构、API 与共享样例见[平台知识库](../../../docs/knowledge-base/README.md)；正式规格、变更与技能统一位于平台根。本文及各专题中 Android 工程路径以 `android/` 为根，平台根执行构建时使用 `bash android/gradlew -p android ...`。

本知识库解释当前代码的功能、调用链、设计取舍和验证边界。项目规则与维护入口位于根目录 [AGENTS.md](../../AGENTS.md)；SDK 接入参数以 [配置指南](16-SDK配置指南.md) 为详细参考，模块边界以 [SDK 模块化拆分说明](15-SDK模块化拆分说明.md) 为准。

## 文档分工与维护

- 本知识库及配套文档通过仓库级 [knowledge-sync skill](../../../.agents/skills/knowledge-sync/SKILL.md) 手动更新，普通开发不自动同步；调用方式及归档同步规则见[平台维护约定](../../../docs/knowledge-base/README.md#内容归属与维护约定)。
- 本目录负责机制、调用链、设计取舍和验证范围；不为每个类单独生成一篇说明。
- [平台知识库](../../../docs/knowledge-base/README.md)维护跨端架构与约定，[API 文档](../../../docs/api/README.md)维护服务端正式契约，[客户端接入文档](../../../docs/client-integration/README.md)维护事件构造、上传、持久化和重试步骤；本目录通过链接引用这些内容。
- [15 SDK 模块化拆分说明](15-SDK模块化拆分说明.md) 维护全量和精简接入、发布及 JNI 迁移边界。
- [16 SDK 配置指南](16-SDK配置指南.md) 统一维护配置字段、默认值与限制。
- [17 FPS 算法说明](17-FPS算法说明.md) 统一维护 FPS 公式、统计口径和典型日志。
- 00 维护 Android 能力与实现限制，11 维护验证方法和证据，12 维护差异和待处理问题；跨端与部署状态引用平台状态页。
- 13 描述 `memory_peak_summary` 运行峰值累计与补报；Activity 泄漏检测使用独立事件、队列和上传器，统一见 14。
- 源码链接使用仓库相对路径，正文用类名与函数名定位，避免把易漂移的行号作为唯一依据。

## 事实来源与验证入口

客户端行为以本仓库源码为依据，服务端要求以 [API 文档](../../../docs/api/README.md)为依据。两者不一致时同时记录，不能用文档抹平差异。测试源码只说明存在覆盖；测试通过需要执行记录，设备能力需要设备证据。外部 Rhea 二进制内部机制未经检查的部分保留为验证边界。

[构建测试](11-构建测试与本地发布.md)维护最近完整主机基线、专项方法与设备证据；[平台状态](../../../docs/knowledge-base/00-当前实现与验证边界.md)维护跨端验收与部署摘要，本导航不复制结果。历史文档中的包名/group 改写及其证据限制见[命名与发布迁移](11-构建测试与本地发布.md#命名与发布迁移)。
