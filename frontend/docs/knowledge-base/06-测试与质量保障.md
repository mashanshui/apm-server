# 测试与质量保障

本页维护前端测试命令、覆盖和浏览器证据边界。日常运行输出留在任务结果或 CI，最近完整基线原位更新；后端计数与 Python 打包结果不复制到本页。

## 验证命令

在 `frontend/` 执行（Windows 可使用 npm.cmd）：

```bash
npm run typecheck
npm test
npm run build
```

代码改动按风险执行相关测试与类型检查；依赖、构建配置、路由或发布资源变化时执行生产构建。测试成功和构建成功不能替代真实后端浏览器验收。

## 仍需重点验证的页面行为

- 真实浏览器中快速修改筛选、应用和指标时的网络取消时序。
- 真实后端下 `no_data`、`no_valid_data`、`denominator_insufficient` 和部分接口失败的完整页面联调。
- 大事件列表、超长调用树和长时间多算法趋势的性能基线。
- 详情不存在、无权限、无异常链和 `raw_only`。
- 浏览器刷新 Crash 与卡顿 history 深层路由时的生产静态服务器 fallback。
- 1280、1440、1920 像素 PC 视口下带正式后端登录态的完整页面与角色回归；移动端不在当前范围。
- 长指纹、长异常消息和超长堆栈的可读性。
- 图表 resize、销毁和空数据状态。

## 联调与验收边界

组件测试、模拟页面、真实 HTTP、真实数据库和登录态浏览器各有独立范围。已有部分正式后端浏览器验收，不能笼统写成“尚未联调”，也不能扩大为全页面、全角色或正式生产 E2E。

Android SDK 生命周期、生产 HTTPS/Secure Cookie、完整越权矩阵、跨浏览器、可访问性和大数据量页面性能仍需验收。固定数据与统计期望见[Crash](../../../docs/crash-fixed-dataset.md)和[内存](../../../docs/memory-fixed-dataset.md)，跨端索引见[平台测试](../../../docs/knowledge-base/08-测试与质量保障.md#跨端证据索引)。
