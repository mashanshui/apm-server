## 联调与验收边界

前端页面仍只记录 UI/服务端 API 消费边界，不把云端 HTTP 结果当作正式浏览器 E2E。processor `1.0.2` 已使用客户端实际设备 ZIP 完成 UUID v4 主线程-only 解析及云端 Jank 首次写入、重复和详情回传；前端页面本身仍未覆盖生产 Android SDK 生命周期、真实 R8 mapping 连续查询或正式后端登录态浏览器 E2E。登录页及合成 API 驱动的真实 Vue 创建页、Owner/Admin 查看 Key、Developer/Viewer 只读和凭据错误状态已在 1280、1440、1920 像素 PC 视口检查且无页面级横向溢出；合成 API 仅监听本机、未修改仓库或使用真实密码，因此仍不等同于正式后端登录态浏览器 E2E。这不等同于：

- 自动化 ClickHouse 集成测试。
- 大数据量查询和前端性能验收。
- 生产网关、HTTPS、正式浏览器端到端和多租户运营验收。
- 生产静态服务器与网关验收。
- 浏览器兼容性和无障碍完整验收。

固定数据与统计期望见[Crash 固定验收数据集](../../../docs/crash-fixed-dataset.md)和[内存固定验收数据集](../../../docs/memory-fixed-dataset.md)，平台级测试边界见[测试与质量保障](../../../docs/knowledge-base/08-测试与质量保障.md)。
