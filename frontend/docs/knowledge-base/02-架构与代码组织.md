# 架构与代码组织

## 运行时数据流

```text
Vue 页面
  → Pinia Session/App Store 或页面 composable
  → 统一 HTTP 客户端（Cookie + CSRF）
  → Vite 开发代理或生产同源网关
  → Spring Boot 认证/应用/Crash/卡顿/内存 Controller
  → Session 与 app_member 授权
  → PostgreSQL 管理数据 / ClickHouse 或内存 Crash、Jank、Memory 仓库
```

前端只依赖 HTTP 查询契约，不知道 ClickHouse 的地址、账号、表结构，也不决定后端使用哪种仓库。

## 工程结构

```text
frontend/
├─ docs/knowledge-base/  # 前端知识库
├─ src/
│  ├─ api/               # HTTP 客户端、认证/应用/Crash/卡顿/内存 API 与错误模型
│  ├─ components/        # 页面复用组件
│  ├─ composables/       # 页面查询编排、并发控制和分页状态
│  ├─ router/            # Vue Router 路由表与认证守卫
│  ├─ stores/             # Pinia 会话和应用状态
│  ├─ types/             # 认证、应用、Crash、卡顿和内存 API 类型
│  ├─ utils/             # 查询状态与显示格式化
│  ├─ views/             # 路由页面
│  ├─ App.vue            # 根路由出口
│  ├─ main.ts            # Vue 应用入口
│  └─ style.css          # 当前全局样式
├─ index.html
├─ package.json
├─ tsconfig.json
├─ vite.config.ts
└─ vitest.config.ts
```

## 分层职责

| 层次 | 当前职责 | 主要文件 |
|---|---|---|
| 页面 | 读取路由、组合组件、触发导航、组织页面状态 | `src/views/*.vue` |
| composable | 并发请求、取消旧请求、分页合并、错误状态 | `src/composables/*.ts` |
| Store | 当前用户、Session 初始化/过期、应用列表/当前应用和清理 | `src/stores/session.ts`、`src/stores/apps.ts` |
| API | URL、Cookie/CSRF、参数编码、响应解析、统一 401 和错误 | `src/api/http.ts`、`src/api/*.ts` |
| 类型 | 与后端 JSON 契约对应的认证、应用、Crash、卡顿和内存结构 | `src/types/*.ts` |
| 组件 | 筛选器、图表、表格、状态卡片和堆栈展示 | `src/components/*.vue` |
| 工具 | URL 查询状态、日期和指标格式化 | `src/utils/*.ts` |

## 当前关键设计

- 筛选状态保存在 URL 查询参数中，页面刷新和下钻返回时可以恢复上下文。
- 总览页并行加载总览统计、趋势和问题排行。
- 页面切换或筛选变化时使用 `AbortController` 取消旧请求，并以请求令牌避免旧响应覆盖新状态。
- 问题和事件分页使用游标追加，并按指纹或事件 ID 去重。
- 卡顿域使用独立的 `types/jank.ts`、`api/jankApi.ts`、`utils/jank*.ts` 和 `composables/useJank*.ts`；问题、Issue、事件和指标页面复用这些边界，不把结果写入全局 Store。
- 内存域使用独立的 `types/memory.ts`、`api/memoryApi.ts`、`utils/memoryQuery.ts` 和 `composables/useMemoryMetrics.ts`；summary/trend 请求各自维护状态，PSS/VSS/Java 堆百分位只在展示层切换，不写入全局 Store。
- ECharts 只按需注册折线图、网格、提示框和 Canvas 渲染器。
- `VITE_API_BASE_URL` 未设置时使用相对 `/api`；本地由 Vite 代理，生产应由同源网关提供同等路由。
- 认证和应用数据只保存在 Pinia 运行时内存，不写入 `localStorage` 或 `sessionStorage`；Session 由 HttpOnly Cookie 携带，CSRF Token 仅从 Cookie 读取并用于请求头。
- 收到 401 时统一派发 `apm:auth-expired`，清理用户和应用状态并跳转登录；卡顿指标页切换应用时进入目标指标页，Issue/事件详情切换时进入目标问题列表，旧 composable 请求由路由变化和 `AbortController` 清理。

## 依赖基线

实际版本以 `package.json` 和 `package-lock.json` 为准。当前核心依赖是 Vue 3、Vue Router、Pinia、ECharts、TypeScript、Vite、Vitest、Vue Test Utils 和 `vue-tsc`。

`appApi.ts` 提供独立 `getIngestCredential` 请求；完整 Key 只存在于 `AppSettingsView.vue` 的局部 `ref`。应用切换、会话过期、请求失败、路由离开和组件卸载都会中止旧请求并清空 Key，避免旧应用响应覆盖新页面。
