## 2026-10-04 当前代码分析云端发布

本次 124 项前端测试、类型检查及生产构建通过，当前产物已发布至现有 Nginx HTTP 同源入口。实际浏览器登录并查看真实云端版本 4 报告，成功状态、未知停止、当前引用匹配及宿主自报信息可见；按 PC 基线检查。截图和限定范围见[云端发布验收](../../../docs/analysis-validation/cloud-current-code-validation.md)，不代表 HTTPS 或设备端修复通过。

## 当前开发形态

前端是独立 Vite 工程，Spring Boot 当前不托管其静态资源。Vite 开发服务器和 `/api` 代理只用于本地开发，不是生产网关。

## 目标生产形态

```text
浏览器
  → HTTPS 同源网关或静态 Web 服务器
      ├─ / 与静态资源 → frontend 构建产物
      └─ /api          → Spring Boot
```

生产托管至少需要：

- HTTPS 和安全响应头。
- `/api` 到 Spring Boot 的同源反向代理。
- Vue Router history 路由回退到 `index.html`。
- 静态资源缓存策略与版本回滚能力。
- 环境化 API 基地址；优先保持同源相对路径。
- 构建、发布、健康检查和回滚的 CI/CD 记录。

仓库现已提供 `docker/nginx.conf` 和 `compose.cloud.yaml` 的小规模云端 Web 运行形态：Nginx 提供静态资源、Vue history fallback，并将 `/api` 和 `/ingest` 代理到 Spring Boot。该配置当前只监听 HTTP 80，尚未提供域名、HTTPS、证书自动续期、CSP 完整策略或正式 CDN/回滚流程；`npm run build` 成功仍不等同于这些生产能力已经完成。

## 当前安全边界

- 前端不接触 ClickHouse URL、用户名或密码。
- 前端不发送 Android 上报用的应用 Key。
- 前端使用同源 Session Cookie；状态变更请求发送 `X-XSRF-TOKEN`，不把密码、Session 标识或 CSRF Token 写入 Web Storage。
- 401 由统一 HTTP 客户端转换为会话过期事件，清理 Pinia 用户/应用状态并跳转登录。
- 页面只消费服务端已经脱敏的异常内容。
- Crash 请求不发送 `X-App-Id` 或 `X-User-App-Ids`；服务端根据认证主体和成员关系授权。
- 路由中的 `appId`、`fingerprint` 和 `eventId` 都是用户可控输入，服务端必须独立鉴权和校验。
- 404 的前端兜底文案不区分资源不存在与无权限，避免帮助枚举资源。
- 应用查询 Token 仅在创建响应中展示完整值；组件关闭、应用切换、卸载或 Session 401 时清空。浏览器错误采集和会话回放也必须排除 Token 响应与该 DOM 文本。

## 生产前必须补齐

- OIDC、开放注册、找回密码、多因素认证和成员邀请/角色编辑。
- 生产域名、HTTPS、证书自动续期、安全响应头、CSP 和 Session Cookie Secure 配置。
- 浏览器端到端越权、会话过期和权限变更测试。
- 敏感错误与日志审查，禁止在浏览器暴露数据库或内部实现信息。
- 生产环境、预发布环境和开发环境的配置隔离。
- Key 撤销/轮换仍待补齐；mapping 符号表网页列表、上传和管理员替换已经纳入应用成员权限边界，构建自动上传、下载和删除仍未实现。

平台级安全决策见[安全与隐私](../../../docs/knowledge-base/06-安全与隐私.md)和[ADR-JVM-CRASH-004](../../../docs/knowledge-base/10-架构决策记录.md)。

完整应用 Key 只允许在设置页组件局部内存中短暂存在。生产 CSP、错误采集、会话回放和前端日志工具不得采集该 DOM 文本或接口响应；复制操作由用户显式触发，页面不会写入 Web Storage 或 URL。

查询 Token 与 Android 上报 Key 是不同凭据。前端只通过 Session/CSRF 调用[查询 Token 管理 API](../../../docs/api/query-token-api.md)，不会把查询 Token 自动加入网页查询或上传请求。MCP 当前允许 HTTP 调试接入；2026-09-29 云端 Web/MCP 已部署，`/login` 和无凭据 MCP 入口冒烟通过。云端有效 Token 工具调用与受信 HTTPS 网关仍需后续验收，见[Agent 查询链路记录](../../../docs/agent-query-e2e-validation.md#2026-09-29-云端部署与入口冒烟)。

## 查询 Token 与外部入口开关

应用设置页仅对 OWNER/ADMIN 提供查询 Token 管理。后端 APM_AGENT_QUERY_ENABLED=false 时拒绝新 Token 创建和外部 Agent 查询，但已有 Token 列表与撤销仍可通过网页管理；前端创建失败按服务端错误展示。MCP_ENABLED 为独立服务开关，默认关闭；当前 MCP 不因缺少 HTTPS 代理标记拒绝 HTTP 调试请求。HTTP 上传输 Bearer 有明文泄露风险，受信 HTTPS 仍是后续生产化要求。前端自身不保存或自动转发查询 Token，接口见 [Token 管理 API](../../../docs/api/query-token-api.md)。
