# 产品范围与当前状态

## 当前目标

前端当前承担邮箱登录、应用工作区、JVM 致命 Crash 和卡顿监控的排障闭环。卡顿页面遵循“指标观察 → 问题聚合 → Issue 事件 → 单事件采样证据”的路径，仅覆盖浅色 PC 控制台。

已实现能力：

- 使用邮箱和密码登录，恢复服务端 Session，处理 401 会话过期并安全退出。
- 通过应用列表、搜索、创建和设置页形成应用工作区；创建者自动成为 `OWNER`。
- 按当前用户成员关系访问应用，角色展示为 `OWNER`、`ADMIN`、`DEVELOPER` 或 `VIEWER`。
- 展示启动会话、Crash 事件、崩溃会话、受影响设备、每千会话崩溃率和无崩溃会话率。
- 按小时或天展示 Crash 事件趋势。
- 按版本、渠道、环境、Android 版本、设备型号、问题指纹和时间范围筛选。
- 查看 Crash 问题排行、指纹下的事件列表和单事件详情。
- 区分 `ok`、`no_data` 和 `denominator_insufficient` 统计状态。
- 展示 `dataSource`，用来识别 ClickHouse 数据或内存联调数据。
- 展示脱敏异常链、原始堆栈、应用帧标记和 `raw_only` 状态。
- 调用卡顿总览/趋势/Issue/事件，以及 FPS、设备日挂起率、统一指标趋势和白名单多维 API；请求沿用同源 Session、401 和应用路径隔离。
- 从 URL 解析/序列化卡顿公共与指标筛选；挂起率固定为 UTC `day`，并使用请求取消、令牌隔离和游标去重基础设施。
- 展示卡顿事件/会话/设备/精确消息耗时总览、问题趋势和 Issue 排行，区分精确消息耗时与采样估算堆栈耗时。
- 从 Issue 事件列表下钻到单事件，展示采样覆盖与空洞、采集质量、实际采样帧、递归估算调用树和 SVG 估算火焰图。
- 展示场景 FPS 与设备日挂起率的区间汇总、按算法版本的多系列趋势和白名单多维分析，分别处理 `no_data`、`no_valid_data`、`denominator_insufficient` 与合法零值。
- 在共享侧栏中区分卡顿指标和问题分析；从卡顿详情切换应用时回到目标应用问题列表，不携带旧指纹、事件或游标。

## 与其他模块的边界

| 能力 | 前端职责 | 非前端职责 |
|---|---|---|
| 查询条件 | 从路由读取、编辑并序列化筛选条件 | 校验最大时间范围、分页上限和超时上限 |
| 应用范围 | 从路由取得 `appId`，通过同源 Session 请求应用 Crash/卡顿 API | 后端依据认证主体和 `app_member` 判断权限 |
| 统计口径 | 按服务端状态正确展示数值、空值和说明 | 去重、分组、Crash 率与无崩溃会话率计算 |
| 数据存储 | 展示服务端返回的数据源标识 | 访问 ClickHouse、选择内存或持久化仓库 |
| Crash/卡顿内容 | 展示服务端返回的异常链、精确消息耗时与采样证据 | 校验、脱敏、生成问题指纹和统计聚合 |
| 生产安全 | 不保存密码、Session 标识、CSRF Token、ClickHouse 凭据或 Android 上报 Key | 后端执行登录、Session/CSRF、应用成员授权和租户隔离 |

## 当前不包含的能力

- 开放注册、OIDC、找回密码、多因素认证、成员邀请和角色编辑。
- 成员邀请/角色编辑、应用删除、mapping 或符号表管理。
- Issue 生命周期、负责人、评论、状态流转和回归检测。
- ANR、NDK/native Crash、非致命异常、启动和网络页面。
- 卡顿 Issue 负责人、状态、标签、评论、操作日志、现场数据、版本对比和导出。
- 正式堆栈反混淆与符号化操作。
- 生产静态资源托管、同源网关、HTTPS 和 CI/CD 发布配置。
- 移动端适配；设计和验收仅覆盖宽度不小于 1280 像素的 PC。

## 与 Grafana 的分工

Grafana 继续负责内部趋势分析、临时查询、运维观察和告警；Vue 前端承载需要产品交互和逐层下钻的页面。当前 Vue 不通过 `iframe` 嵌入 Grafana，而是直接调用 Spring Boot 查询 API。

平台级范围与路线图见[平台产品目标与范围](../../../docs/knowledge-base/01-产品目标与范围.md)和[平台实施路线图](../../../docs/knowledge-base/09-实施路线图.md)。

应用创建页展示 `name`、`description` 和唯一的全小写 Android application ID，其中只有 `packageName` 必填；名称为空时服务端使用包名作为默认显示名称，描述为空时保存为空。服务端生成 UUID v4 `appId`，应用设置页对所有角色展示只读 `appId`/包名，仅 `OWNER`/`ADMIN` 可按需查看、隐藏和复制永久 appKey。appKey 默认不请求，也不进入通用 App Store、URL 或 Web Storage；应用列表、切换器、面包屑和工作区标题以 `name` 为主要展示文本。
