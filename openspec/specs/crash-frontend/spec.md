## Purpose

为项目成员提供可直接使用的 JVM Crash 分析页面，使用户能够从统计总览逐级定位到 Crash 问题、具体事件和脱敏后的原始堆栈，并正确理解无数据与统计分母不足等状态。

## Requirements

### Requirement: Crash 总览与筛选

前端 MUST 提供项目 Crash 总览页面，展示启动会话数、Crash 事件数、崩溃会话数、受影响设备数、每千会话崩溃率、无崩溃会话率、时间趋势和问题排行。页面 MUST 支持项目、时间范围、应用版本、渠道、环境、Android 版本、设备型号和问题指纹筛选，并将同一组筛选条件应用到相关查询结果。

#### Scenario: 首次打开 Crash 总览

- **WHEN** 用户打开一个项目的 Crash 总览页面
- **THEN** 页面使用默认时间范围查询总览、趋势和问题排行，并显示统计卡片、趋势图和问题列表

#### Scenario: 使用筛选条件刷新数据

- **WHEN** 用户修改时间范围或任一 Crash 维度筛选条件并提交
- **THEN** 页面使用新的筛选条件刷新总览、趋势和问题排行，并明确显示当前筛选状态

#### Scenario: 筛选条件无效

- **WHEN** 服务端返回时间范围、筛选值或请求参数校验错误
- **THEN** 页面保留用户输入，显示可理解的错误信息，并允许用户修正后重新查询

### Requirement: 统计状态和查询状态呈现

前端 MUST 保留服务端返回的 Crash 统计语义。比例字段为 `null` 或统计状态为 `denominator_insufficient` 时，页面 MUST 显示分母不足或不可计算，不得显示为零；统计状态为 `no_data` 或列表为空时，页面 MUST 显示无数据。查询过程中 MUST 显示加载状态，查询失败时 MUST 显示可重试的错误状态。

#### Scenario: 存在有效分母且没有 Crash

- **WHEN** 查询结果包含有效启动会话分母、Crash 事件数为零且状态为 `ok`
- **THEN** 页面显示真实的零 Crash 结果和可计算的比例，而不是无数据

#### Scenario: 缺少启动会话分母

- **WHEN** 查询结果的比例字段为 `null` 且状态为 `denominator_insufficient`
- **THEN** 页面将比例显示为分母不足或不可计算，并保留其他可用的计数指标

#### Scenario: 查询范围没有数据

- **WHEN** 查询结果状态为 `no_data` 或趋势、问题列表为空
- **THEN** 对应区域显示无数据提示，不将空结果渲染为零值趋势或虚假的问题

#### Scenario: 查询请求失败

- **WHEN** 网络请求超时、服务端返回 5xx 或返回未预期的错误响应
- **THEN** 页面显示错误提示和重试入口，且不使用上一次查询结果冒充当前结果

### Requirement: Crash 问题和事件下钻

前端 MUST 允许用户从问题排行进入指定指纹的问题事件列表，再从事件列表进入单事件详情。问题列表和事件列表 MUST 支持服务端返回的 `nextCursor` 分页，并在没有下一页时隐藏或禁用继续加载操作。下钻请求 MUST 继续使用当前项目和有效筛选条件。

#### Scenario: 从问题排行查看事件

- **WHEN** 用户选择一个 Crash 问题
- **THEN** 页面展示该指纹的事件列表，并显示事件时间、版本、构建、渠道、环境、系统、设备、异常类型和符号化状态

#### Scenario: 加载下一页问题或事件

- **WHEN** 当前响应包含非空的 `nextCursor` 且用户请求下一页
- **THEN** 页面使用该游标加载下一页并追加或替换对应列表，不重复已有记录

#### Scenario: 没有更多结果

- **WHEN** 响应的 `nextCursor` 为空
- **THEN** 页面不再发起下一页请求，并明确表示列表已经到底

### Requirement: Crash 事件详情和堆栈展示

前端 MUST 展示单个 Crash 事件的项目、应用、发生时间、接收时间、版本、构建、渠道、环境、Android 版本、设备、会话、异常类型、指纹和符号化状态。页面 MUST 展示服务端返回的脱敏异常链及堆栈帧，包括异常类型、异常消息、类名、方法名、文件名、行号和应用帧标识；不得要求事件必须已经符号化才能查看原始堆栈。

#### Scenario: 查看原始堆栈事件

- **WHEN** 用户打开一个 `symbolicationStatus=raw_only` 的 Crash 事件
- **THEN** 页面显示原始异常链和堆栈，并明确标识当前尚未完成符号化

#### Scenario: 查看不存在或无权限的事件

- **WHEN** 事件详情接口返回 404 或项目访问被拒绝
- **THEN** 页面显示事件不存在或无权访问的通用提示，不展示其他项目是否存在或其事件数据

### Requirement: 浏览器请求的项目范围与凭据安全

前端 MUST 使用当前服务端用户会话访问 Crash 查询接口，并为每个请求绑定路由中的当前项目范围。服务端 MUST 根据认证主体与项目成员关系独立授权，MUST NOT 把 `X-Project-Id`、`X-User-Project-Ids`、URL 参数或浏览器状态视为用户身份及成员关系证明。前端 MUST NOT 在浏览器代码、请求、存储或日志中使用 Crash 上报用的 `X-Project-Key` 或其他项目密钥。

#### Scenario: 请求当前项目数据

- **WHEN** 已登录项目成员为当前项目发起任一 Crash 查询
- **THEN** 请求携带服务端会话并绑定当前项目路径，服务端确认成员关系后返回数据，且浏览器不会发送上报项目 Key

#### Scenario: 切换项目后查询

- **WHEN** 用户从一个项目切换到另一个有权访问的项目
- **THEN** 页面清理或重新校验旧项目的查询结果，后续请求只使用新项目范围，不能将旧项目数据显示在新项目页面中

#### Scenario: 访问无成员关系的项目

- **WHEN** 已登录用户通过修改 URL 或请求头访问没有成员关系的项目 Crash 页面
- **THEN** 服务端拒绝查询并使用不泄露项目是否存在的响应，页面不展示目标项目或旧项目数据

#### Scenario: 会话失效后查询

- **WHEN** Crash 查询返回未认证或会话过期响应
- **THEN** 页面停止展示当前项目的受保护数据并进入统一的重新登录流程
