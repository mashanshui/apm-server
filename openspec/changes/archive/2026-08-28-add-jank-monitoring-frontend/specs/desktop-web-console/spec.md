## ADDED Requirements

### Requirement: 控制台提供卡顿分析导航并保持模块上下文

项目控制台 MUST 在 JVM Crash 之外提供卡顿监控导航，并明确区分卡顿指标分析和卡顿问题分析。用户从任一卡顿页面切换项目时，系统 MUST 进入目标项目的对应卡顿稳定入口并重新请求数据，不得默认跳回无关模块或复用旧项目的 Issue、事件、指标结果和筛选状态。

#### Scenario: 在项目控制台查看卡顿导航

- **WHEN** 用户打开任一有项目上下文的控制台页面
- **THEN** 侧栏提供卡顿监控入口，并在卡顿页面正确标识当前卡顿子模块

#### Scenario: 从卡顿指标页切换项目

- **WHEN** 用户在某项目的卡顿指标页选择另一个可访问项目
- **THEN** 页面进入目标项目的卡顿指标页，保留兼容的指标视图但重新加载目标项目数据

#### Scenario: 从卡顿详情页切换项目

- **WHEN** 用户在卡顿 Issue 或事件详情页选择另一个可访问项目
- **THEN** 页面进入目标项目的卡顿问题列表，不携带原项目的指纹、事件 ID、游标或详情数据
