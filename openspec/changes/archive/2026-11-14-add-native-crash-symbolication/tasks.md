# Native Crash 后台符号还原实施任务

以下任务按 [设计](design.md) 和五份增量规范实施；复选框反映实际实现与验证状态，已完成任务保持勾选，新增 AGP 符号包任务在完成相应验证前保持未完成。生产方法、变量补充标准注释，成功和失败均记录必要安全日志，不输出堆栈、文件内容、秘密或设备现场。

- [x] 1.2 固定 LLVM 19 发行修订、校验摘要、许可及资源限制启动器，更新后端镜像与显式工具路径配置；在目标 Linux 镜像验证版本、非 root 执行、512 MiB/CPU 限制及缺依赖可解释延期，不在运行时自动下载。
- [x] 1.3 实现受控参数数组、按模块批量地址输入、JSON/内联/函数名解析与路径处理；测试有效函数、函数名缺失、行号零、C++ 名称、内联链顺序、64 位地址、禁止外部调试路径及原始 stderr 不泄露。

- [x] 1.6 同步后端 `symbol-mapping.md`、`05-构建配置与本地运行.md` 和 `06-测试与质量保障.md` 中工具依赖、预算、测试命令与已验证边界；核对文档命令可复现。

## 3. Native 帧与 Java 栈独立处理

- [x] 3.2 实现 Native 成功帧永久排除、函数名即成功、同来源确定性失败跳过及临时失败退避；测试成功后换成更丰富 SO 不补行号、删除重传不改来源、未成功帧可按新修订重试。

- [x] 3.4 实现事件内未尝试单元优先、到期重试轮转及 Native/Java 独立预算；可控时钟测试前部慢模块、后部线程、工具不可用时 Java 仍完成，以及预算未开始单元不被伪报解析失败。
- [x] 3.5 实现主栈三态和逐状态帧数、独立剩余工作标记，所有变化走整快照发布；测试主栈完成但辅助仍待处理、部分成功/失败、无主栈有 Java，以及完整快照超限时不回退已确认成功。
