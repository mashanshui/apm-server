## Why

当前 Vue 前端只能通过 URL 中的 `projectId` 和可伪造的开发请求头访问 Crash 页面，缺少真实用户登录、项目选择、创建与基础管理入口，无法形成可用于多项目场景的产品闭环。现在需要补齐服务端会话和项目工作区，使用户能够安全地从登录进入自己有权限的项目，并在统一的浅色 PC 控制台中完成项目创建、管理和 Crash 分析。

## What Changes

- 新增邮箱与密码登录、服务端 Session、会话恢复、过期处理和安全退出；暂不提供开放注册和第三方 OIDC 登录。
- **BREAKING**：正常运行环境新增 PostgreSQL 连接要求，用于持久化用户、项目、成员关系和服务端 Session；现有本地启动脚本与部署配置必须同步提供数据库配置。
- 新增用户、项目和项目成员关系，创建者自动成为项目 `Owner`，所有项目资源均按当前登录用户和成员关系执行服务端授权。
- 新增项目列表、项目搜索、空状态、创建项目和项目基础设置页面；支持查看项目标识与当前角色，以及按权限修改项目名称和描述。
- 将 Crash 页面接入项目工作区，移除未知路由跳转到 `demo-project` 的开发期行为，并停止把 `X-Project-Id` / `X-User-Project-Ids` 当作网页用户身份来源。
- 重构共享控制台布局，加入项目切换器、用户菜单、退出入口和项目设置导航；视觉统一改为浅色，仅面向 PC 浏览器设计和验收，不实现移动端或窄屏响应式布局。
- 增加登录、会话、项目授权、项目管理、路由守卫和关键页面状态的自动化测试，并同步平台与前端中文知识库。
- 本变更不包含开放注册、OIDC、成员邀请与角色编辑、App 管理、上报 Key 轮换、mapping 管理和项目物理删除。

## Capabilities

### New Capabilities

- `web-user-authentication`: 网页用户使用服务端 Session 完成登录、会话恢复、过期处理、受保护路由访问和退出登录。
- `project-management`: 已登录用户按成员权限列出、搜索、创建、查看和修改项目基础信息。
- `desktop-web-console`: 提供统一的浅色 PC 控制台布局、项目切换、用户菜单和项目级导航，不承诺移动端适配。

### Modified Capabilities

- `crash-frontend`: Crash 页面改为依赖真实登录会话与项目成员授权，并从项目工作区进入和切换项目。

## Impact

- 后端需要引入 Spring Security、服务端 Session、密码哈希、PostgreSQL 持久化以及 Flyway 迁移，并新增认证、会话和项目管理 API。
- 现有查询授权链路需要从开发请求头切换为认证主体和项目成员关系，Crash API 的成功响应结构保持不变，但浏览器凭据与错误处理方式发生变化。
- 前端将新增认证与项目领域的 API、类型、状态管理、路由守卫和页面，并调整 `AppLayout`、路由默认跳转及全局样式。
- 测试需要覆盖登录失败、会话过期、跨项目访问、角色写权限、项目创建校验、重复项目标识、加载/空/失败状态以及 PC 视口下的页面行为。
- 平台和前端知识库中的当前实现、安全边界、路由、API、测试与本地启动说明需要在实现时同步更新。
