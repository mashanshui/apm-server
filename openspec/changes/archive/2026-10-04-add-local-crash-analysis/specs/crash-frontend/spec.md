## ADDED Requirements

### Requirement: 单事件分析交互
事件详情页 MUST 提供单 eventId 分析入口、任务状态、无凭据自然语言指令及本地准备指引、阻断原因、结果与分页历史。OWNER/ADMIN/DEVELOPER 可创建，VIEWER 仅查看。页面 MUST 展示执行策略、宿主来源和实际可取得的模型信息，未知或自报必须明确标识，明确结果只针对选中事件；应用或事件切换后旧响应不得覆盖新状态，结果文本必须安全转义。

#### Scenario: 创建后手动执行
- **WHEN** 有权成员在详情页创建分析
- **THEN** 展示任务及不包含凭据的 Skill 调用及准备指引，网页不声称本地已自动启动

#### Scenario: 缺失前提
- **WHEN** 任务缺少映射、对应提交或所需 mapping
- **THEN** 展示可理解原因和补齐后重新检查入口，不显示正在调用模型

#### Scenario: 切换和恶意结果
- **WHEN** 用户切换应用或事件，或结果包含 HTML 脚本
- **THEN** 丢弃旧响应且不执行结果中的脚本

### Requirement: 最小分析配置入口
网页 MUST 提供管理员构建映射登记、更正和 Worker 凭据创建/撤销入口，普通成员不得写入配置。执行策略仅展示宿主分析及实际来源，不提供服务地址或 API Key 管理。凭据创建结果 MUST 禁止缓存，离开页面或关闭后清除完整值。

#### Scenario: 开发者与管理员权限
- **WHEN** DEVELOPER 可以创建分析但尝试更改构建映射或创建 Worker 凭据
- **THEN** 服务端拒绝管理操作，网页不提供可执行管理入口

### Requirement: 报告完成与宿主停止分别展示
页面 MUST 分别显示分析结果、本地工具关闭和宿主停止事实，未知模型/用量不得显示为固定模型或零。SUCCEEDED 报告但 stopConfirmed=false MUST 明示宿主停止未确认，重试入口不得绕过原门禁。管理员核验入口 MUST 提示实际确认本次宿主分析结束，不能只凭材料工具关闭。

#### Scenario: 宿主停止未知
- **WHEN** 报告成功但宿主停止 UNKNOWN
- **THEN** 报告可查看，停止未确认可见，不自动重试或声称模型已中止
