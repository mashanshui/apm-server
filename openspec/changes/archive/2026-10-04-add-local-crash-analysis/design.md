# 单事件宿主 Agent 本地分析设计

> 历史归档（2026-10-04）：本变更已完成 46/46 项，其执行方案已由 [add-current-code-crash-fix](../2026-10-04-add-current-code-crash-fix/tasks.md) 替代。保留原提案、设计、实施和验收事实，本次跳过旧规范同步；当前行为以[正式规范](../../../specs/current-code-crash-fix/spec.md)为准。

## 交付增量：Skill 内置 Python 运行时

唯一 Worker 源码放在 agent-skills/apm-crash-analyze/worker，根 agent-worker 保留开发用相对链接，避免双份源码漂移。Skill 脚本根据自身位置调用 uv run --project，使用 Python 3.12、uv.lock 与生产依赖，保持调用者当前目录和 CLI 退出码；不读取当前目录的 .env。宿主需要 Python 3.9+ 启动器、uv 与 Git，首次安装联网且 Skill 目录可写。运行时依赖 POSIX 文件锁，支持 macOS/Linux，Windows 使用 WSL。

共享打包脚本按明确文件列表导出 ZIP，只包含当前宿主执行链路；旧 OpenCode/Docker 模块、测试、配置、虚拟环境和真实验收记录不随包交付。工具与历史执行器共用受限材料清理模块，宿主入口不再导入旧执行器。平台凭据、仓库映射和原私有状态放在安装目录之外；重新安装不能绕过任务恢复与停止门禁。独立解压运行验证只证明运行时可安装，不替代其他宿主的实际任务验收。

## Context

动机见 proposal.md。现有实现已经具备网页任务、冻结证据、Python 固定提交快照、独立 Worker 身份、90 秒租约、20 秒心跳、10 分钟期限、结构化结果和引用核验。当前 CLI run 启动隔离 OpenCode/DeepSeek，后端要求固定配置与整个环境停止，Skill 仅启动命令；这些是旧实现，不是新流程已完成的事实。

本次由当前宿主直接推理，Python 不调用模型。宿主权限、模型请求和运行进程通常不由本工具控制，不能继续沿用旧容器停止与请求前模型预算的保证。现有 TypeScript MCP 仅只读查询，不扩展其权限。

## Goals / Non-Goals

目标：固定输入、最小只读工具、可核验源码引用、独立任务控制、真实来源与未知事实、幂等恢复、保留历史。

非目标：宿主通用框架、模型选择器、源码编辑、构建、修复、MR、云端调度、MCP 重写，以及将提示词当作宿主操作系统沙箱。

## Decisions

### 1. 本地命令工具而非新增 MCP

复用 Python 3.12、httpx、Pydantic、pytest。提供 prepare、read、search、submit、status、stop 的任务命令；共同绑定 taskId、平台及私有状态目录。命令名在实现中冻结到 README。prepare 校验本地仓库和权限后领取、验证证据摘要并返回脱敏证据、证据 ID、固定 SHA 与操作指引。read/search 只接收快照相对路径或有界搜索词，不返回整个仓库路径、原始源码、秘密或租约。

每 Run 启动一个有限生命周期的 Python 看护进程，维护心跳及撤销、取消、期限检测；不引入常驻 HTTP 服务、队列或 MCP。命令与看护短暂获取同一私有文件锁，原子更新恢复记录。所有材料操作须重新核验当前分配与租约，过期及网络未知时拒绝继续，不依赖宿主偶尔主动发送心跳。

替代方案：仅导出目录让宿主自行读取更简单，但不能核验读取事实与撤销后访问；新增 MCP 增加协议和身份范围。首版使用现有 CLI 通道的受控读取接口。

### 2. 固定提交与读取核验

沿用仓库映射、精确 origin、完整 SHA、干净快照、签名排除、凭据脱敏、链接/子模块/LFS 阻断。宿主不把当前 HEAD 或未提交修改作为分析输入。本任务接口只读，无任意命令、编辑、构建、网络抓取能力；宿主其他工具权限仍由本机用户授权。

Python 为成功 read 记录路径和实际返回行范围，提交引用必须由同 Run 读取记录覆盖。search 结果不能代替 read 的引用证明。引用片段由 Python 从固定原文重新生成脱敏文本与摘要，不接受模型自行填写片段。限制单次读取 200 行、8192 UTF-8 字节，文件 16 MiB、搜索数量 100、累计向宿主交付材料 512 KiB；超过明确失败，不静默截断有效引用。

### 3. 宿主执行来源与模型未知

新任务配置为 HOST_AGENT 执行策略，不预设 DeepSeek 或 OpenCode。结果 schemaVersion=2；旧结果 schemaVersion=1 仅作为历史展示。执行信息包括 mode、host、hostVersion、providerId、modelId、metadataSource；可选值未知使用 null，来源区分 HOST_REPORTED 和 UNKNOWN，不能将宿主或模型自报标为平台验证。用量只接受可信宿主运行统计；首版无法获取时全部 null，不从文本长度估算。

Python 生成固定 mode、工具版本与材料/引用事实。首版仅通过 --host 接收非敏感宿主名称并标为自报，宿主版本、providerId/modelId 与全部用量保持 null；不提供模型输入参数。历史执行字段保留供旧报告读取。后端核对任务策略和结果版本，不用固定模型 ID 拒绝合法宿主结果。旧数据不迁移成新模型事实。

### 4. 任务状态与停止分离

保留 Task/Run 领取、幂等、租约、期限与状态机。新 Run 保存 localToolsStopped 和 hostStopState（UNKNOWN/CONFIRMED）；原 stopConfirmed 仍代表整个本次执行已核验停止，只有本地工具关闭且可信宿主进程核验或管理员审计成立时才为 true。不能仅由模型传一个布尔值确认宿主停止。

正常 submit 先核验并固定结果原文与摘要，关闭本地材料访问，再幂等回传。成功可以保存 SUCCEEDED 报告但 stopConfirmed=false、hostStopState=UNKNOWN；网页明确报告完成与宿主停止未确认是不同事实，原身份/任务的新尝试继续被门禁阻止。管理员在实际确认宿主本次分析结束后留依据确认停止；不必关闭整个桌面应用。失败、取消、到期关闭本地工具，保留宿主未知，不接受迟到结果。管理员确认前有效活动任务须先取消。

首版没有通用宿主进程控制器，不接受 Agent 自报 CONFIRMED。看护无法观察宿主进程时只报告工具关闭。结果回传失败保留同 Run 与同摘要，恢复不再推理。读取私有状态不是宿主获取报告的途径。停止未知不自动删除恢复证据，已关闭材料视图可按受信清理流程处理。

### 5. 预算能力边界

Python 强制单并发、材料交付字节、每操作资源上限、租约与总期限；后端继续单应用三活动任务、数据库有界历史和 30 天内容保留。工具不能约束宿主此前或后续模型请求数、Token、缓存和费用，不宣称已有硬限制或自动中止。取消/失联只能确认本任务工具停止；宿主终止须额外实际核验。

### 6. Skill 和网页

Skill 明确已有 UUID、只读搜索/读取、异常链分析、多候选和证据不足、严格 JSON 结果以及真实提交状态。宿主不读私有配置、原始快照或数据库，不造用量和执行证明。配置不再要求 Docker、独立执行器或 DeepSeek key；平台地址、Worker 工程、仓库映射和私有状态目录从可信本地配置确定。

网页展示自然语言指令及工具准备指引，显示任务策略、实际来源与未知模型；旧历史保留原 DeepSeek/OpenCode 字段。成功报告和停止未知均可见，显式重试仍受门禁约束。OWNER/ADMIN/DEVELOPER、Session/CSRF 与查询 Token 的隔离不变。

### 7. 验收与文档

重新验证准备失败零材料泄漏、跨任务访问、目录穿越、链接越界、取消、租约、后台心跳、读取记录覆盖、格式/引用校验、同摘要恢复、停止未知与管理员确认。首个真实宿主以当前 Codex 实际读取、推理和提交核验；不把旧 CLI 调用当作新宿主分析通过。保留旧五样本评估，新增宿主样本及人工核对，分别说明实现、入口、分析与模型质量。

实施同步根、后端、前端知识库、API、Worker/Skill 和验收记录，检查导航与本地链接。Android 事件契约和既有 MCP 不变。

## Risks / Trade-offs

- 当前宿主可使用其他授权工具 → 明示工具边界；本任务接口拒绝扩权，不能宣称隔离整个宿主。
- 模型身份和用量不可观察 → null 与来源标记，不伪造固定模型或成本。
- 正常报告保存后宿主停止仍未知 → 报告可读，新尝试阻止，实际人工核验后留审计。
- 背景看护崩溃、系统睡眠或网络中断 → 材料操作每次校验租约，过期拒绝，恢复原分配不自动推理。
- 模型分析仍可能格式错误或猜测 → 严格核验与人工样本评估，不以宿主替换保证质量提升。

## Migration Plan

追加 Flyway 列用于新停止事实，不修改旧脚本。新创建及重新准备的无证据任务采用 HOST_AGENT；已有冻结输入和结果保留原配置，不把旧 READY 隐式换策略，需网页创建新任务。关闭旧 OpenCode 本地执行入口，保留旧历史展示和必要原 Run 对账材料，不保留双模型执行框架。

后端、Python/Skill、前端配套更新，默认开关仍关闭；试点明确开启后验收。回滚保留新表列与审计，先停用新任务及核验活动会话，避免旧版本按容器语义误确认宿主停止。云端仅保留无本地绝对路径的输入输出契约，不预埋云端执行。
