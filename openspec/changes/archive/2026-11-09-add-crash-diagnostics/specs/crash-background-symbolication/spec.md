# Crash 辅助线程后台还原规范增量

## MODIFIED Requirements

### Requirement: 持久化还原状态与首次成功终态
系统 MUST 持久化 pending、failed、symbolicated 主异常状态及安全原因。pending/failed MUST 保留可重试的脱敏原始异常链；symbolicated MUST 仅提供单份完整主异常还原堆栈，并记录实际符号表唯一身份、版本或摘要及处理时间。首次主异常成功结果 MUST 固定；重复执行、替换、删除和重新上传 mapping MUST NOT 再次还原或覆盖该事件。其他线程的当前堆栈和独立处理状态 MUST 随该次成功发布固定，未成功的辅助栈 MUST 明确保留原始帧及失败原因，不能伪装成全部已还原；非堆栈诊断上下文 MUST 不随还原改变。

#### Scenario: 成功后只使用固定结果
- **WHEN** 某事件已成功还原，随后 mapping 被替换或删除后重新上传
- **THEN** 主异常堆栈、正式指纹、处理来源和已发布辅助线程结果保持原值，后续详情及后台任务不重新执行该事件的 Retrace

#### Scenario: 失败保留材料
- **WHEN** 主异常解析失败、输出超限或存储临时不可用
- **THEN** 系统保留原始异常链、其他线程材料和可解释原因，不发布截断结果，不标记主异常成功

#### Scenario: 完整候选与未变化输出
- **WHEN** R8 返回内联、多候选或与输入相同的完整输出
- **THEN** 系统保留完整输出，按明确的成功处理语义记录来源，不任取候选，不将输出未变化直接视为失败，也不声称所有帧都已正确还原

#### Scenario: 主异常成功而辅助线程失败
- **WHEN** 主异常完整还原成功，但部分辅助线程失败或耗尽辅助预算
- **THEN** 允许发布主异常成功与正式归组，同时固定辅助线程的原始帧和独立失败原因，页面不能将主异常状态当成辅助线程成功状态

### Requirement: 成功发布幂等且可对账
系统 MUST 在成功发布前确定唯一终态内容，将主异常完整堆栈、正式指纹、状态、来源和其他线程当前堆栈及处理结果作为同一逻辑版本发布。响应未知时 MUST 重放相同版本和相同结果，不重新选 mapping 计算；过期执行者和迟到失败写入 MUST NOT 覆盖已确定的成功结果。事件原身份、发生时间、接收时间及不可变诊断上下文 MUST 保持不变。

#### Scenario: 写入成功但确认丢失
- **WHEN** 已存成功结果但后台未收到确认，任务随后恢复
- **THEN** 对账或重放同一主异常及辅助线程结果，事件保持单个逻辑结果和首次成功来源，统计不增加

#### Scenario: 发布过程中查询
- **WHEN** 用户在后台发布或恢复期间查询事件与问题
- **THEN** 每个响应使用一致的当前主异常、辅助线程和归组版本，不组合新指纹与旧堆栈，不隐藏完整可用的待处理详情

#### Scenario: 事件过期
- **WHEN** 待发布事件超过有效数据保留期
- **THEN** 系统清理或结束对应工作，不通过回放恢复已经过期的遥测事件

## ADDED Requirements

### Requirement: 其他线程复用主异常后台处理来源
其他线程 MUST 使用主异常首次成功尝试持有的同一实际 mapping 处理，保持采集时的线程身份、顺序与元数据；处理 MUST 有线程数、输入、输出和总等待预算。正式指纹 MUST 仅使用主异常还原材料，MUST NOT 混入其他线程的帧、状态或日志。没有 mapping 或主异常尚未成功时，其他线程原始材料 MUST 仍可查看。

辅助线程的单项失败 MUST NOT 使完整可用的主异常失败；成功辅助栈只保留一份当前还原文本，失败栈保留原始帧并标记原因，空帧栈 MUST 明确为不适用还原。主异常成功发布后，本版 MUST NOT 对失败辅助栈另启补算或因新 mapping 改写结果。

#### Scenario: 缺少 mapping
- **WHEN** 带其他线程材料的事件等待 mapping
- **THEN** 主异常和其他线程的已采集原始材料均可查看，详情不调用实时还原

#### Scenario: 同一来源还原多个线程
- **WHEN** 主异常及多个其他线程在本次后台处理中取得完整还原输出
- **THEN** 输出保留线程边界、完整内联和候选，实际 mapping 来源一致，正式指纹只由主异常产生

#### Scenario: 空堆栈和辅助输出超限
- **WHEN** 一个线程为空帧，另一个线程的还原输出超过辅助预算
- **THEN** 空帧线程不被标记为还原失败，超限线程保留原始帧和 output_limit 原因，不截断输出伪造成功

#### Scenario: 辅助结果固定
- **WHEN** 主异常成功时某个辅助线程已记录失败，之后上传新的 mapping
- **THEN** 该事件主异常和辅助结果均保持已发布状态，不为辅助失败重新打开主异常终态
