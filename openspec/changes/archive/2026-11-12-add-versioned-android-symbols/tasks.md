# Android 符号表版本管理实施任务

以四份增量规格及 [design.md](design.md) 为准。事件 buildId 保持必填；仅 mapping 登记可省略构建。Rhea SDK 与 processor 固定 1.0.4，不修改外部 btrace。复核实现和测试后才标记完成；未完成的上传、后台和端到端任务不因范围收敛视为已实现。

## 1. 收敛上报范围并复用 Jank 1.0.4

- [x] 1.1 定向撤回全链路可空构建模型、校验、Schema、存储转换、队列格式、临时指纹 v2 及网页/MCP 适配；保持既有 SDK 默认和显式非空构建、Leak 服务端原契约，回归上报拒绝缺失构建及各端测试，同步根、Android、前端知识库和上报/客户端文档。
- [x] 1.2 保留 Jank 同一不可变 ZIP 的版本预检、回调包名/构建核对、最终身份校验和统一选择器；以实际 1.0.4 JAR/ZIP 测试有构建解析、缺失拒绝和幂等，核对依赖目录及后端/客户端 Jank 文档。

## 2. 符号元数据与迁移

- [x] 2.1 保留类型、版本、SO 字段及可空登记构建，建立版本默认、构建专用、SO 三类活动唯一索引；真实 PostgreSQL 验证升级、NULL 唯一性、身份共存和审计保留，同步存储知识库。
- [x] 2.2 为版本工作增加稳定身份、版本、扫描游标及唯一约束，退役旧任务并给 publication 增加版本门禁；真实迁移验证租约/未确认发布阻止、排空切换及原文件、审计、成功来源和序列保留，同步切换与恢复说明，不清空遥测。
- [x] 2.3 验证元数据类型适用约束及旧无版本登记投影：默认 mapping 构建为空，专用保留原值，SO 无应用构建；实体和 HTTP 测试覆盖旧登记可见不可匹配，同步符号表 API。

## 3. mapping 默认与专用管理

- [x] 3.1 修改 mapping 上传、幂等、条件替换/删除及事务唤醒，按版本和选填登记构建区分资源；测试独立 revision、默认并发唯一、跨版本及提交未知文件保留，同步 API 和客户端示例。
- [x] 3.2 统一选择器以事件非空构建先选专用，再选同版本默认，固定实际文件租约；测试默认回退、跨版本/其他构建不猜测、专用不可读不回退及旧租约完成，同步后端符号表说明。
- [x] 3.3 扩展数据库列表与游标的类型、版本、mappingScope 和 SO 身份筛选；测试完整筛选绑定、权限和非法条件，使用 10 万行 EXPLAIN ANALYZE 验证边界，同步列表契约。

## 4. 版本后台与 Jank 来源

- [x] 4.1 将唤醒、租约、计数、对账和进度合并到应用版本并持久化扫描位置；测试重启、通知竞争、默认上传及非重置第一页，同步版本进度和调度知识库。
- [x] 4.2 数据库按版本与最新状态先取最多 100 个轻量候选，再按非空构建选文件并仅取有限载荷，固定子批租约；使用既有百万数据基线和无匹配前页、迟到、大诊断测试验证有界公平推进，同步性能证据。
- [x] 4.3 以实际 symbolId/revision 判断失败重试和来源变化，保留首次成功 publication 字节；测试默认/专用切换、删除、不可读和确认丢失，成功不重算、Native 不入队，同步生效语义。
- [x] 4.4 以真实 1.0.4 processor 验证有构建 Jank 的专用/默认、无 mapping、查询失败和租约释放；既有事件不回算，补齐后端及客户端说明和对应测试。

## 5. SO 归档、身份及批次管理

- [x] 5.1 保留固定 Commons Compress 依赖及最小四 ABI 夹具源码和临时生成步骤；检查依赖树及实际夹具，不提交预编译 SO 或运行产物，同步夹具和构建说明。
- [x] 5.2 保留只读 ELF32/64 ABI、完整 GNU Build ID、函数符号和调试段检测；以四 ABI 和损坏 note/表/字符串/溢出/仅 dynsym 夹具验证安全边界，同步检测能力说明。
- [x] 5.3 完成 ZIP 中央目录及实际读取预算，拒绝穿越、链接、重复、嵌套、加密、ZIP64、CRC 和伪造大小；归档炸弹、中断及清理测试验证整批失败不发布，核对归档安全说明。
- [x] 5.4 SO multipart 解析前限制单实例并发，落实 deadline、磁盘余量、清理及阶段日志；真实 Servlet 验证慢流、中断、权限/CSRF 提前拒绝与许可释放，同步安全配置。
- [x] 5.5 联动 Spring multipart、环境变量、Nginx 与超时，保留 mapping 32 MiB 业务上限；验证真实大小边界和内存报告共享入口，同步部署与预算。
- [x] 5.6 实现版本内 ABI/完整 ELF Build ID 身份、同摘要合并及目标模块检查，不接收应用 buildId；测试同名多 ABI、跨版本、完整 ID 与目标不符，同步 SO 身份契约。
- [x] 5.7 完成 SO 全批冲突快照和各项预期身份/revision/不存在条件的原子确认；PostgreSQL 测试新建竞争、同内容幂等、全回滚及提交确认丢失，同步冲突和重试示例。
- [x] 5.8 完成 native-batches、条件删除及受控文件发布回收；验证权限/CSRF、重启、SO/旧登记进度不适用且不唤醒 JVM，核对 Native 原始材料不变，同步 API 和客户端 SO 说明。

## 6. 网页符号管理与入口

- [x] 6.1 扩展符号类型/API、版本与默认/专用表单，SO 无应用构建控件；测试 FormData、批次确认、类型切换、旧响应隔离及 SO 不轮询，同步页面/API/状态知识库。
- [x] 6.2 JVM 详情预填 appVersion 和原 buildId，可在上传时清空以选版本默认；Native 只携带版本及模块 ABI/ELF 身份，验证路由、权限、未知目标与离页，并显示版本本轮进度、保存不代表还原，同步交互说明。

## 7. 跨端集成核验

- [x] 7.1 隔离 PostgreSQL/ClickHouse、真实 HTTP、1280px 网页和有效 Token MCP 验证有构建上报、默认/专用、版本隔离及 SO 批次/删除/重启；核对既有查询不变和 Native 原始材料，保存必要截图及有限证据。
- [x] 7.2 执行后端 clean build、恢复后的 Android JVM 测试、前端 test/typecheck/build 和 MCP 检查，报告条件跳过；核对四份规格证据、任务状态、文档归属与链接，运行严格 OpenSpec 校验。环境状态仅在实际重验时原位更新，不新增操作流水。

- [x] 7.3 修复核验 W1：区分 SO 归档/ELF 内容错误与接收后超时、中断及磁盘 I/O 故障，保持 422/413 与可重试 503；补充接口分类、整批无副作用、暂存清理及提交后文件保留测试，同步错误语义与核验结论。
