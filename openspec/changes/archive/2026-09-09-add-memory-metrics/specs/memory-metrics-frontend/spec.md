## Purpose

为应用成员提供与现有控制台一致的内存指标分析页面，通过 PSS、VSS、Java 堆三个指标的统计卡片和分位数趋势观察内存变化，并清楚区分查询失败、无样本与真实零值，避免用户误读数据。

## ADDED Requirements

### Requirement: 提供三个内存指标页签

控制台 MUST 在应用上下文中提供 `/apps/:appId/memory-metrics` 及内存指标导航，采用已有浅色 PC 布局。页面 MUST 仅提供 PSS、VSS、Java 堆三个指标页签，默认 PSS；MUST 不展示 FD 触顶率、多维下钻、对比列表或导出。

#### Scenario: 打开内存指标页面
- **WHEN** 已授权应用成员进入页面
- **THEN** 页面依次显示三个指标页签、筛选区、概览卡片和趋势区，并展示当前应用

### Requirement: 筛选和地址状态一致

页面 MUST 提供时间范围、小时/日粒度、应用版本、系统版本、机型、进程、Activity 名称（`scene`）和前后台筛选，不得显示 32/64 位筛选。前后台 MUST 可选择全部、前台、后台。筛选、指标、粒度 MUST 在 URL 中可恢复；非法 URL 参数 MUST 提示修正。切换应用 MUST 清理旧应用数据与筛选，并忽略未完成的旧请求响应。

#### Scenario: 刷新筛选结果
- **WHEN** 用户设置版本和后台筛选后刷新地址
- **THEN** 页面恢复相同筛选并按相同参数请求当前应用数据

#### Scenario: 切换应用时旧请求返回
- **WHEN** 用户切换到另一应用后原应用请求才完成
- **THEN** 页面只显示新应用结果，旧响应不得覆盖数据

### Requirement: 展示概览和分位数趋势

页面 MUST 展示所选指标的平均值、P50、P90、P95、P99 五张卡片，并显示有效样本数。趋势 MUST 支持 P50/P90/P95/P99 切换，默认 P50，使用服务端桶统计；MUST 将字节除以 1048576 显示为 MiB 并保留两位小数，明确时间显示时区。不得在浏览器重算总体统计或将空桶连接成连续有效数据。

#### Scenario: 切换趋势分位数
- **WHEN** 用户从 P50 切换 P95
- **THEN** 趋势使用响应中的 P95 值，概览卡片保持同一筛选条件下的服务端统计

#### Scenario: 区分零值和无数据
- **WHEN** 某桶真实值为零，另一桶无样本
- **THEN** 前者展示 0.00 MiB，后者为折线断点；空概览显示暂无数据而非 0.00

### Requirement: 独立呈现查询状态

概览和趋势 MUST 分别处理加载、无数据、失败及重试；未登录和无权限 MUST 遵循控制台既有处理，不能将错误呈现为成功空数据。页面 MUST 在 1280、1440、1920 像素宽 PC 视口保持主要操作可见。

#### Scenario: 趋势失败但概览成功
- **WHEN** 概览请求成功而趋势请求失败
- **THEN** 保留有效概览，趋势显示错误和重试入口，不伪造曲线
