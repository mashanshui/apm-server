# 卡顿查询规格增量

## MODIFIED Requirements

### Requirement: 提供卡顿总览、趋势、Issue 和事件查询
系统 MUST 提供项目范围内的卡顿总览、时间趋势、Issue 排行、Issue 个例列表和单事件详情查询。查询 MUST 支持时间、应用版本、渠道、环境、Android 版本、设备型号、场景、指纹和算法版本筛选，并限制最大时间范围、返回数量、游标和执行时间。


总览、趋势、Issue 和事件页 MUST 基于筛选时间窗内全部逻辑事件计算，`limit` MUST 只控制列表返回条目，MUST NOT 截断统计输入。去重、计数、设备/会话集合和耗时分位数 MUST 在内存验证模式与持久化模式保持一致；分位数使用升序第 `max(1, ceil(N*p))` 个有效值，无有效值返回 null。总览及趋势收到合法 limit 时仍 MUST 返回完整统计，非列表入口携带 cursor MUST 返回 `400 INVALID_CURSOR`。

Issue MUST 按事件数降序、最近发生时间降序、指纹升序；事件 MUST 按发生时间降序、事件 ID 升序。列表 MUST 返回版本化不透明 nextCursor，绑定应用、列表类型、首次实际绝对时间窗、全部有效筛选及排序位置。继续请求省略时间时 MUST 恢复原时间窗；旧格式、损坏、跨应用、跨指纹、跨列表或筛选不匹配的游标 MUST 返回 `400 INVALID_CURSOR`，不得回到第一页。静态数据集在同一查询上下文下 MUST 能完整遍历且不重不漏；游标不承诺新增或迟到事件下的快照一致性。

查询 MUST 受执行时间、扫描行数/字节数、数据库内存及响应字节预算保护；超时返回 `408 QUERY_TIMEOUT`，资源超限返回 `422 QUERY_RESOURCE_LIMIT`，存储不可用返回可重试的 `503 EVENT_STORE_UNAVAILABLE`。失败 MUST NOT 返回空数据或带成功状态的部分统计。网页与只读 Agent 查询 MUST 共用统计语义，允许各自保留已发布的页大小上限。

#### Scenario: 查询卡顿总览
- **WHEN** 已授权用户查询存在卡顿数据的项目和时间范围
- **THEN** 系统返回卡顿次数、受影响会话数、受影响设备数、精确卡顿耗时分位数和可归组事件数

#### Scenario: 查询 Issue 排行
- **WHEN** 已授权用户按相同筛选条件查询卡顿 Issue
- **THEN** 系统返回指纹版本、事件数、受影响设备数、首次和最近发生时间、精确卡顿耗时分位数及明确标记的估算关键堆栈耗时分位数

#### Scenario: 下钻单个卡顿事件
- **WHEN** 已授权用户通过 Issue 选择一个事件
- **THEN** 系统返回公共事件信息、精确消息耗时、场景、采样时间片、调用树、堆栈字典、估算字段和采集质量

#### Scenario: 查询范围无数据
- **WHEN** 筛选范围内没有合法卡顿事件
- **THEN** 系统返回明确的 `no_data` 状态和空结果，不伪造零分位数

#### Scenario: 跨项目访问卡顿数据
- **WHEN** 当前用户不是目标项目成员，或无权查看该项目
- **THEN** 系统拒绝总览、Issue 和事件详情查询，不泄露目标项目是否存在

#### Scenario: 事件数量超过默认页大小
- **WHEN** 一个时间窗包含 120 个唯一事件、60 个 Issue，并分别使用 limit=20 和 limit=50 查询
- **THEN** 总览和趋势均覆盖 120 个事件；Issue 计数及耗时分位数覆盖该 Issue 全部事件，不随页大小改变

#### Scenario: 多页遍历及并列排序
- **WHEN** 静态数据中存在超过一页的 Issue 和同一 Issue 下的事件，且部分排序值相同
- **THEN** 连续使用 nextCursor 可遍历全部匹配条目，最后一页游标为空，条目不重复、不遗漏

#### Scenario: 省略时间的续页请求
- **WHEN** 首次查询省略 from/to，并在稍后持相同筛选和 nextCursor 继续查询
- **THEN** 系统沿用首次响应的绝对时间窗，返回稳定排序的后续页

#### Scenario: 游标与查询上下文不匹配
- **WHEN** 用户提交旧纯指纹游标、损坏游标，或更换应用、指纹、场景、算法版本、时间或其他筛选后复用旧游标
- **THEN** 系统返回 `400 INVALID_CURSOR`，不返回第一页或其他查询的数据

#### Scenario: 查询预算耗尽
- **WHEN** 合法查询超过执行时间、扫描量、数据库内存或响应字节预算
- **THEN** 系统返回对应的 408 或 422 错误，不返回部分计数或截断趋势

#### Scenario: 网页与 Agent 对照
- **WHEN** 网页用户与该应用查询 Token 对同一静态数据集使用相同筛选
- **THEN** 两种入口得到相同总数、分位数和排序，在各自页大小下均能遍历完整结果
