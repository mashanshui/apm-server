# 当前实现与验证边界

内存指标已切换运行期观测峰值，服务端独立验收及 Performance 联合 J1..J7 已通过：用户指定 Pixel_6 模拟器的真实采集、启动中断、503/响应丢失重试、升级原版本归属与隔离 ClickHouse/HTTP/Dashboard/MCP 对齐。默认前台10秒/后台30秒已有客户端频率实验；不代表真机功耗或生产容量。本地 Docker 已升级到峰值版本，云端尚未升级，历史普通样本证据不覆盖新链路。详见[统一验收](../validation/memory-runtime-peaks/README.md)。

JVM Crash 已增加有界诊断上下文及辅助线程独立还原，API 29/35 模拟器到隔离服务的采集、断网补传和 Release mapping 已完成有限验证；API 35 模拟器的一条原始 Crash 也已从认证失败隔离队列恢复并上传到本地服务。最低 API 及真机验证仍有缺口，云端未更新，详见[诊断验收](../validation/crash-diagnostics/README.md)。

当前源码已增加 Native Crash 客户端采集和启动恢复、服务端接收与临时归组，以及网页和 MCP 的原始详情读取；API 29/35 arm64 模拟器已完成真实信号、重启补传与隔离服务查询，其他 ABI、真机和生产边界见 [Native 验证](../validation/native-crash/README.md)。本地后端、网页、MCP 及 ClickHouse 011 已更新；云端尚未更新，本地设备应用仍需安装包含新版 SDK 的构建。

本页集中回答当前能力、验证层级和不能对外承诺的范围。最近本地部署核验见下表；文档核对日期不代表测试或云端部署重验，外部证据以各自执行日期和范围为准。

仓库结构于 2026-11-08 核对：Android Performance 源码与原 Git 历史已纳入 `android/`，与后端、前端和 MCP 保持独立构建；OpenSpec 与技能统一使用平台根入口。各端当前可复用测试入口见[平台测试](08-测试与质量保障.md)及 [Android 构建测试](../../android/docs/knowledge-base/11-构建测试与本地发布.md)。合仓不代表现有本地服务、云端或设备应用已更新。
