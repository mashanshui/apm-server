# 当前实现与验证边界

本页集中回答当前能力、验证层级和不能对外承诺的范围。代码与配置核对日期为 2026-10-22；文档核对日期不代表测试或部署重验，外部证据以各自执行日期和范围为准。

## 状态口径

| 标记 | 含义 |
|---|---|
| 已实现 | 仓库中存在对应代码、配置或资源 |
| 自动化已验证 | 有测试覆盖；实际执行范围和跳过项见各工程测试页 |
| 外部环境已冒烟 | 在真实数据库、HTTP 或浏览器环境完成有限验证，不能外推生产容量 |
| 目标能力 | 尚未完整实现的设计，见[路线图](09-实施路线图.md) |
| 待确认 | 尚需业务、容量、安全或运维决策，见[待确认事项](13-待确认事项.md) |

- 启动耗时、网络、完整 ANR、NDK/native Crash、非致命异常、Issue 工作流及移动端页面。
- 构建自动上传、mapping 下载/删除、原生 SO 符号化、HPROF 解析、附件下载和内存详情页。
- Protobuf、上报通用限流、Kafka、通用归档及正式告警；Agent 查询限额和内存附件清理已实现。
- 生产 HTTPS、备份恢复、容量/SLA、多实例和长期故障演练。
- 云端修复执行器、审批发布与确定性 CI 验证；当前工作区与历史 APK 的对应关系仍未知。

## 验证证据边界

| 证据 | 可以说明 | 不能说明 |
|---|---|---|
| 单元/MockMvc/组件测试 | 测试输入下的协议、状态、授权和失败分支 | 真机行为、真实浏览器或外部依赖可用性 |
| SQL/Schema/Grafana 资源检查 | 资源结构和约束声明 | 数据库执行、插件权限或告警可用性 |
| PostgreSQL/ClickHouse 集成 | 独立测试数据库中的迁移、语义和有限资源边界 | 生产备份、高可用、混合负载和长期 TTL 成本 |
| 构建和容器健康 | 产物可生成、进程/健康检查成立 | 所有业务依赖、有效凭据查询或完整端到端验收 |
| HTTP/浏览器冒烟 | 指定日期、环境、样本与页面链路成立 | 全角色、跨浏览器、生产安全或容量 |
| 宿主分析报告 | 报告已保存及宿主自报事实 | 历史源码一致、独立修复验证或宿主已停止 |

可复用检查方法和证据索引见[平台测试](08-测试与质量保障.md)；工程命令与测试条件由[后端](../../backend/docs/knowledge-base/06-测试与质量保障.md)和[前端](../../frontend/docs/knowledge-base/06-测试与质量保障.md)分别维护。
